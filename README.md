本仓库整理《Head First 设计模式（第二版）》的学习讲解、练习题及 Python 示例，供个人学习设计模式时参考。

## 资料目录

目前已整理以下章节：

- [第1章：设计模式介绍](第1章设计模式介绍/讲解稿.md)
- [第2章：观察者模式](第2章观察者模式/讲解稿.md)

每个章节包含：

- `讲解稿.md` / `讲解.html`：章节讲解。
- `练习题.md` / `练习题.html`：学习练习与测验。
- `示例.py`：Python 示例代码。

## 使用方式

可直接在 GitHub 阅读 Markdown 文件，或下载到本地后用浏览器打开 HTML 文件。Python 示例可在对应章节目录中运行：

```bash
python 示例.py
```
