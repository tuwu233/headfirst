QUESTION 07单选题10 分名单快照
以下代码只进行一轮通知，最后打印什么？
seen = []
observers = []


def a():
    seen.append("A")
    observers.remove(b)


def b():
    seen.append("B")


observers.extend([a, b])
for callback in tuple(observers):
    callback()
print(",".join(seen))
QUESTION 08单选题10 分异常传播
这段代码没有逐个捕获回调异常。两行输出分别是什么？
state = {"temperature": 20}
seen = []


def bad():
    raise RuntimeError("broken")


def good():
    seen.append("good")


try:
    state["temperature"] = 30
    for callback in (bad, good):
        callback()
except RuntimeError:
    print("failed")
print(state["temperature"], seen)
