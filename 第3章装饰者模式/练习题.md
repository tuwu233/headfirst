```python

    def cost(self):

    def __init__(self, inner):
        self.inner = inner

    def cost(self):
        return self.inner.cost() + 10


class Half:
    def __init__(self, inner):
        self.inner = inner

    def cost(self):
        return self.inner.cost() // 2

print(AddTen(Half(Coffee())).cost())
```

### 第 9 题

Soy 应持有内部 Beverage，并将描述与价格委托后增强；双份豆奶需要包装两次。以下代码与本章示例一同使用。

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class Soy:
    beverage: Beverage

    def description(self):
        return self.beverage.description() + " + 豆奶"

    def cost(self):
        return self.beverage.cost() + 250


drink = Whip(Soy(Soy(Espresso())))
assert drink.cost() == 2500
assert drink.description().count("豆奶") == 2
```

- 5 分：持有内部对象，description 与 cost 都按相同接口委托并增强。
- 5 分：正确组合双份豆奶和最外层奶泡，检查 2500 分和两份描述，未修改已有类。
