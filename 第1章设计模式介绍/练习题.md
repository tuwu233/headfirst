### 第 9 题

把 mode 选择移到组装入口，checkout 只调用传入的函数。若 mode 来自外部输入，入口仍要校验未知值。

```python
def normal(weight):
    return weight * 200


def express(weight):
    return weight * 400


def checkout(goods_cents, weight, shipping):
    return goods_cents + shipping(weight)


assert checkout(1000, 2, normal) == 1400
assert checkout(1000, 2, express) == 1800
```

- 5 分：checkout 接收并调用统一签名的策略，不再根据 mode 分支。
- 5 分：提供两种策略和两次正确调用，指出选择策略仍由入口负责。
