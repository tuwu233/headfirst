QUESTION 08单选题10 分函数引用
以下代码执行到最后一行会怎样？注意 fly 与 fly() 的区别。
def fly():
    return "飞行"


class Duck:
    def __init__(self, behavior):
        self.behavior = behavior

    def perform_fly(self):
        return self.behavior()


duck = Duck(fly())
print(duck.perform_fly())
QUESTION 09应用题 · 自评10 分重构练习
下面的结算函数很快要支持更多运费规则。用 Python 改成接收运费函数的写法，并展示普通和加急两种调用。要求：新增规则时不修改 checkout；金额单位均为整数分，weight 为正数。
def checkout(goods_cents, weight, mode):
    if mode == "normal":
        fee = weight * 200
    elif mode == "express":
        fee = weight * 400
    else:
        raise ValueError("未知配送方式")
    return goods_cents + fee
